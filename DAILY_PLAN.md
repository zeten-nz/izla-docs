# Izlan — Daily Plan

> Daily Plan — Learner'ning kundalik learning workspace'i. "Lesson 4 ni bajaring" degan oddiy topshiriq emas.
> Bog'liq qarorlar: D-16..D-19, D-26 ([PRODUCT_DECISIONS.md](PRODUCT_DECISIONS.md)).

## Inputs — Daily Plan nimadan hosil bo'ladi

```
Roadmap
+ Learner schedule (weekly target)
+ Available time (bugungi)
+ Current progress
+ Recent mistakes
+ Weak skills
+ Daily missions
→ Daily Plan
→ AI personalization
```

AI personalization Daily Plan'ni Learner'ning holatiga moslaydi, lekin Roadmap'ni yashirincha o'zgartirmaydi (D-13).

## Tuzilishi — 3 tur element

### MUST DO

Roadmapdagi asosiy learning — bugungi asosiy lesson(lar) yoki davom etayotgan lesson qismi.

### RECOMMENDED

AI/tizim weak areas va recent mistakes asosida tavsiya qilgan review/practice. Masalan:

> "Present Perfect'da bir xil xato bir necha marta qaytdi — 10 daqiqalik review tavsiya qilinadi."

Learner buni bajarishi shart emas — tavsiya.

### EXTRA

Learner xohlasa: library, speaking practice, extra exercises, community, review va boshqalar. Bular prerequisite talab qilmaydi va doim ochiq (D-20).

## Available time adjustment

Learner bugun odatdagidan kam (yoki ko'p) vaqtga ega bo'lsa, quick adjustment:

> **Bugun qancha vaqtingiz bor?**
> 30 min · 1 hour · 1.5 hour · 2+ hours

Daily Plan shu vaqtga moslashadi — estimated duration'lar asosida ([LEARNING_SYSTEM.md](LEARNING_SYSTEM.md)) bloklar/elementlar tanlanadi.

## Continuation — lesson bo'linishi

- Lesson bir sessiyada to'liq tugashi **majburiy emas**.
- Progress saqlanadi; keyingi sessiyada Daily Plan'ning MUST DO qismida "davom ettirish" sifatida chiqadi.

## Daily Missions

Learning'ga foydali kundalik missionlar (IZL earning kategoriyasi #4, [REWARDS.md](REWARDS.md)):

- library'da 15 min;
- speaking practice;
- weak topic review;
- bugun o'rgangan narsani community'da tushuntirish;
- boshqa learning missionlar.

## IZL eligibility bilan bog'liqligi

- Bir kunda faqat **asosiy reward-eligible learning target** IZL beradi (D-26).
- MUST DO va Daily Missions — asosiy IZL manbalari; undan keyingi qo'shimcha learning XP/progress beradi, IZL bermaydi.
- Cycle ceiling (20%) tugagan bo'lsa — Daily Plan ishlashda davom etadi, faqat IZL ko'rsatkichlari to'xtaydi.
- Exact daily/weekly allowance — OPEN (economic design).

## Daily Recap

Kun/sessiya yakunida:

```
Today:
68 min learning
1 main lesson
2 reviews
1 daily mission

Grammar +3%
Speaking +1%

+420 XP
+18 IZL

AI: "Present Perfect yaxshilandi, lekin since/for hali review talab qiladi."
```

## Misol user flows

### Flow 1 — oddiy kun

1. Learner kiradi. Daily Plan: MUST DO — "Present Perfect: since/for" lesson (~45 min); RECOMMENDED — Vocabulary review (~10 min); EXTRA — speaking practice, community.
2. Lesson'ni bajaradi: explanation → examples → mini questions → practice → mastery test (92%).
3. Mastery reward IZL beradi (birinchi marta bo'lgani uchun), mini practice'lar Lesson Attention IZL beradi, XP yig'iladi.
4. Recommended review'ni ham qiladi.
5. Daily Recap ko'rsatiladi; weekly target: 2/3 ✓.

### Flow 2 — vaqti kam kun

1. Learner kiradi, "Bugun qancha vaqtingiz bor?" → **30 min**.
2. Daily Plan moslashadi: MUST DO — davom etayotgan lesson'ning practice qismi (~20 min); RECOMMENDED — 1 ta qisqa weak-topic review (~8 min).
3. Lesson tugamaydi — progress saqlanadi, ertaga davom etadi.
4. Qisqa Daily Recap.

### Flow 3 — "yana o'qiyman" kuni

1. Learner MUST DO'ni tugatdi, IZL target bajarildi.
2. U yana 3 lesson o'qishni xohlaydi — **hech qanday cheklov yo'q** (sequence saqlangan holda).
3. Qo'shimcha lessonlardan XP, progress, achievements oladi; IZL olmaydi (daily eligibility tugagan).
4. Daily Recap'da hammasi ko'rinadi: qo'shimcha learning ham, IZL to'xtagani ham.

### Flow 4 — schedule'dan chetlashish

1. Learner'ning target'i: Mon/Wed/Fri. U Wednesday kirmadi.
2. Jazo yo'q. Saturday kirib session qildi — weekly target 3/3 ✓ hisoblanadi (D-16).
3. AI keyingi haftaga schedule adjustment tavsiya qilishi mumkin ("Balki Wed o'rniga Sat qulayroqdir?") — Learner accept qilsa o'zgaradi.
