## Auth
- **login:** `POST /api/auth/login` (phone+password, never OTP) → per-login-page routing.
- **register:** OTP (REGISTRATION) → `POST /api/auth/register` (token in memory) → `/onboarding`.
- **recovery:** OTP (PASSWORD_RESET) → `POST /api/auth/password/reset` → `/login` (**no auto-login**).
- **refresh:** shared single-flight refresh (`X-Izlan-CSRF`, `credentials: include`).
- **error UX:** localized, enumeration-safe; the machine code is never rendered (generic carries no code); applied to
  staff login too.
- **token storage:** access token **memory-only** — never localStorage/sessionStorage/URL.
- **guard:** `LearnerGuard` waits for bootstrap → `/login` if unauthenticated; safe-local `?next` only (no open redirect);
  not role-name gated.

## Onboarding
- **Authority = backend** (`GET /profile/me`, `GET /onboarding/status`, `GET /onboarding/learning-intents`); no local
  "complete" flag; resumable from state.
- **profile:** `PATCH /api/profile/me` (displayName, dateOfBirth, timezone, preferredLanguage).
- **Subject:** `GET /api/onboarding/subjects` (PUBLISHED) → `PUT .../learning-intent {subjectId}` (subject-only).
- **Track:** `GET .../subjects/:id/tracks` → `PUT .../learning-intent {subjectId, trackId}`.
- **completion:** `POST /api/onboarding/complete` **only when `canComplete`** → refresh auth user → `/learn`.
- **empty subject state** shown when nothing is published (the pilot is NOT auto-published).

## Dashboard
- **state composition:** profile + onboarding status + intents, then (if complete) roadmap + today plan.
- **roadmap read:** `GET /roadmaps/me/subjects/:id/active`; 404 → ordinary no-roadmap state.
- **today read:** `GET /daily-plans/today`; 404 → ordinary no-plan state.
- **mutations:** NONE — the dashboard never calls `POST /daily-plans/today`; a page load never mutates learning state.
  No fabricated XP/streak/progress; lesson items show an upcoming (Phase 3.1) marker, not a broken link.

## Design
- **desktop:** calm top bar (brand, Dashboard/Fanlar/Profil, locale, theme, logout).
- **mobile:** compact bottom navigation (Bosh sahifa/Fanlar/Profil); mobile-first; no horizontal overflow.
- **light/dark:** shared `ThemeProvider` (deliberate both ways). **i18n:** uz (default) / ru / en, chrome only.
- **a11y:** semantic headings, labels, `role="alert"` for auth errors, visible focus, reduced-motion aware.
